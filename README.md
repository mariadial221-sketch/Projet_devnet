# Projet DEVNET — Automatisation réseau avec Python, API REST GNS3 et Netmiko

## Contexte

Ce projet met en œuvre une chaîne complète d'automatisation réseau (Infrastructure as Code) :
description déclarative en YAML → déploiement automatique dans GNS3 → configuration via Netmiko
→ validation automatique → génération d'un rapport Markdown.

Aucune configuration manuelle des équipements n'est effectuée : tout passe par le programme Python.
